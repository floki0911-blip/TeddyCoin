# TeddyCoin v9

Добавлена настоящая готовая интеграция с Supabase REST API:

- облачное сохранение профиля;
- онлайн-рейтинг;
- уникальный локальный ID игрока;
- офлайн-режим сохраняется;
- синхронизация после бонусов/заданий;
- экран аккаунта и статус облака.

## Подключение

1. Создай бесплатный проект в Supabase.
2. Открой SQL Editor и выполни `SUPABASE_SETUP.sql`.
3. Открой `app/src/main/java/com/example/teddycoin/SupabaseConfig.kt`.
4. Вставь URL проекта и publishable/anon key.
5. Пересобери приложение.

Не вставляй `service_role` key в Android-приложение.

Важно: текущая версия использует простые публичные RLS-политики, чтобы быстро протестировать игру. Для полноценной системы аккаунтов следующая стадия — Supabase Auth (email/Google/Telegram) и строгие политики, чтобы игрок не мог менять чужой баланс.
