# Сборка APK прямо с телефона через GitHub Actions

1. Открой github.com и войди в аккаунт.
2. Создай новый репозиторий, например TeddyCoin.
3. Загрузи в него ВСЕ файлы этого проекта, включая .github/workflows/build-apk.yml.
4. Открой вкладку Actions.
5. Выбери Build TeddyCoin APK.
6. Нажми Run workflow.
7. После зелёной галочки открой запуск.
8. Внизу найди Artifacts → TeddyCoin-debug и скачай архив.
9. Распакуй архив и установи app-debug.apk.
